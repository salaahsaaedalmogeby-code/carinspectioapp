# نظام الفحص الفني للسيارات - Android v13

نسخة الهاتف المحدثة المبنية على نموذج الفحص الجديد ذي مستطيلات الملاحظات.

## الجديد في v13
- حماية النظام بكلمة مرور.
- أول تشغيل يطلب إنشاء كلمة مرور من 4 أحرف/أرقام على الأقل.
- زر لتغيير كلمة المرور مع طلب الكلمة الحالية أولاً.
- التاريخ يوضع تلقائياً داخل المربع المخصص له في الصفحة الأولى.
- ضبط الملاحظات العامة والتوجيه والتعليق والتجربة الميدانية داخل المستطيلات الجديدة.
- تصوير المحرك كما في النسخة السابقة.
- إضافة 4 صور اختيارية للسيارة من الكاميرا.
- إذا أضيفت أي صورة للسيارة، ينشئ التقرير صفحة رابعة تلقائياً بترتيب 2×2.
- إذا لم تُضف أي صورة، يبقى التقرير 3 صفحات فقط.
- حفظ الصور مع سجل الفحص لتعود عند فتح الفحص للتعديل.
- GitHub Actions جاهز لبناء APK ورفعه كـ Artifact باسم CarInspectionApp-APK.

## البناء عبر GitHub
ارفع محتويات هذا المجلد إلى المستودع ثم افتح Actions > Build Android APK > Run workflow.
بعد نجاح البناء نزّل CarInspectionApp-APK من Artifacts.
