# CarInspectionApp v6

نسخة محدثة تعتمد قالب PDF الجديد المرسل من المستخدم.

## أهم التعديلات
- اعتماد قالب PDF الجديد بالكامل.
- الحفاظ على وضع علامة الصح في مركز خلية الاختيار وليس فوق النص.
- تكبير خط البيانات المكتوبة داخل الخانات لتحسين الوضوح.
- استمرار دعم صورة المحرك/الفحص، تعديل الفحص المحفوظ، وحفظ PDF في Downloads.
