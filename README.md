# نظام الفحص الفني للسيارات - النسخة الأولية

هذه نسخة أولى (MVP) لتطبيق أندرويد مبني على نموذج الفحص الفني المكوّن من 3 صفحات.

## الموجود في النسخة
- إدخال بيانات السيارة.
- فحص الهيكل والبودي.
- فحص الأجزاء الداخلية.
- فحص المحرك.
- فحص ناقل الحركة.
- فحص الدبل والدفرنس.
- فحص التوجيه ونظام التعليق.
- تقييم الإطارات الأربعة.
- كتابة نتيجة التجربة الميدانية.
- تسجيل إشارات فحص الكمبيوتر والطبلون.
- حفظ آخر فحص على الهاتف.
- إنشاء تقرير PDF من 3 صفحات.

## فتح المشروع
1. افتح Android Studio.
2. اختر Open.
3. اختر مجلد CarInspectionApp.
4. انتظر مزامنة Gradle.
5. شغّل التطبيق على هاتف Android أو Emulator.

## ملاحظة
هذه النسخة تركّز على الوظائف الأساسية. يمكن في النسخة التالية:
- جعل التقرير مطابقًا بصريًا للنموذج الورقي الأصلي.
- إضافة شعار المركز.
- قاعدة بيانات لجميع السيارات بدل آخر فحص فقط.
- البحث برقم اللوحة/الهيكل.
- مشاركة PDF مباشرة عبر واتساب.
- إضافة توقيع وختم.
