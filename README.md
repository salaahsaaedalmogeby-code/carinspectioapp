# CarInspectionApp v3

النسخة الثانية من تطبيق نظام الفحص الفني للسيارات.

## الإضافات
- تصوير المحرك بالكاميرا أثناء الفحص مع معاينة وإعادة تصوير.
- وضع صورة المحرك داخل الصفحة الأولى من التقرير مكان الرسم التقريبي للسيارة.
- استخدام ملف التقرير الأصلي ذي الثلاث صفحات كقالب PDF ثابت.
- حفظ التقارير في `Download/تقارير فحص السيارات` على Android 10 وما بعده.
- حفظ عدة فحوصات داخل التطبيق، وفتح أي فحص محفوظ وتعديل بياناته ثم إعادة إصدار PDF.

## البناء
يُبنى APK تلقائياً بواسطة GitHub Actions من workflow الموجود في `.github/workflows/build-apk.yml`.
